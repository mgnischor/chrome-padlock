Padlock은 사용 중인 기기에서 강력한 무작위 비밀번호를 만듭니다. 결과를 한 번에 복사하거나 텍스트 입력란에 바로 삽입하세요.

작동 방식
- 모든 문자는 브라우저의 암호학적으로 안전한 난수 생성기로 선택되며, 강도 표시기는 비트 단위의 정확한 엔트로피를 보여 줍니다.
- 길이(4~128자)와 문자 유형(소문자, 대문자, 숫자, 기호)을 선택하세요. 0, O, 1, l, I처럼 헷갈리기 쉬운 문자를 피하거나 원하지 않는 문자를 제외할 수도 있습니다.
- 결과를 복사하거나, 텍스트 입력란을 마우스 오른쪽 버튼으로 클릭한 뒤 ‘보안 비밀번호 삽입’를 선택하세요.
- 선택 사항: 복사 후 30초~2분 뒤에 클립보드를 자동으로 지웁니다.
- 선택 사항: 최근 생성한 비밀번호 50개의 목록을 보관합니다. 기본값은 꺼짐이며, 암호화되지 않은 채 브라우저 메모리에만 보관되고 Chrome을 닫으면 삭제됩니다.
- 라이트·다크 테마와 30개 인터페이스 언어를 지원합니다.

개인정보 보호
Padlock은 전적으로 사용 중인 기기에서 실행됩니다. 데이터를 수집하지 않고, 네트워크 요청을 보내지 않으며, 광고나 분석 도구도 없습니다. 비밀번호 관리자가 아니므로 아무것도 저장하거나 동기화하지 않습니다.

권한
Padlock은 오른쪽 클릭 메뉴 항목을 사용할 때만 페이지에 접근하며, 사용한 탭과 입력란에만 접근합니다. 클립보드 권한은 선택 사항이며, 클립보드 자동 지우기를 켠 경우에만 요청합니다.
